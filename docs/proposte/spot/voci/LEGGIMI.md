# Voci candidate dello speaker

Tre voci in inglese, stile pubblicità americana anni '90, con le 7 frasi approvate (`docs/proposte/spot/bozza.md`).

| File | Voce |
|---|---|
| `voce_A_uomo_caldo.mp3` | uomo, caldo (Kokoro `am_michael`) |
| `voce_B_uomo_squillante.mp3` | uomo, più chiaro e squillante (Kokoro `am_puck`) |
| `voce_C_donna_sorridente.mp3` | donna, sorridente (Kokoro `af_heart`, la voce migliore del modello) |

- Ogni file ha sopra il filtro leggero "da TV": l'altoparlante piccolo, un poco di compressione e una stanza piccola. Lo stesso file senza filtro è `_pulita.mp3`.
- La frase 6 è già un po' strana: il nastro ondeggia appena, e "Forever." cala.
- La frase 7 rallenta e si abbassa, come un nastro che muore: dal 97 % al 55 % della velocità.
- Controllo con Whisper: tutte le frasi si capiscono. Nella B, "Jilly" si scrive "Jill-ee", perché se no si sentiva "Julie". La B mangia un poco il "The" iniziale della frase 2.
