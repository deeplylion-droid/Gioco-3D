# Mascotte nel gioco: scatti di controllo (21 ottobre)

Scatti dal motore (preset Alto, senza torcia, luce della prima visita), dagli occhi del giocatore, con
gli oggetti montati davvero nel gioco (nodo `Mascotte` di `scenes/sala_principale.tscn`, script
`scripts/environment/mascotte_sala.gd`). Solo per il controllo del coordinatore.

| File | Cosa |
| --- | --- |
| `squalo.jpg` | statua dello squalo A in S2 (bordo est della piscina a onde) |
| `polpoA.jpg` | polpo A in A3 (ingresso dell'area bimbi) |
| `polpoB.jpg` | polpo B in B1 (area bimbi, muro ovest, accanto al fungo) |
| `targa.jpg` | targa JILLY JUBILEE stile B sul lato ovest della vasca di Jilly |
| `manifesto.jpg` | manifesto dello spettacolo sul muro ovest vicino all'ingresso |
| `insegna.jpg` | insegna sopra la vasca d'arrivo con le due lampade a collo d'oca |

Le strisce scure in diagonale sopra il neon, vicino all'insegna, sono le ombre dei ganci del neon
proiettate dalla luce rossa che sta sotto: non sono oggetti (il controllo degli ingombri non trova
nessuna mesh che tocchi l'insegna).
